# Content sheet — dojo-na-ceste

**How this works:** this file is the plain-text surface for all copy + images.
Edit the text right here (change a line, or write `→ REPLACE: your new text`).
Anything you don't touch stays as it is. Hand the file back (or paste a
section into chat) and I sync it into `index.html`. You never touch HTML.

**Images:** drop files into `assets/`. To swap an existing photo, reuse its
exact filename — nothing else changes. For a new slot, use the filename I
suggest below (or your own, just write it next to the slot). Aspect ratio
matters (photos are cropped to fit); resolution: long edge ≥ 1600 px, JPG.

Formatting notes: `–` is an en-dash, `—` an em-dash, `„…"` Czech quotes,
` ` non-breaking space (I'll place these — just write plain text).
