# Content sheet — dojo-na-ceste

**How to use:** edit text in place. For each Aktuality post fill `img:` and
`link:` if you want to add a photo or a button. Anything you leave alone
stays. Hand the file back (or paste sections) and I sync it into
`index.html` — you never touch HTML.

**Images:** drop files into `assets/`. To swap an existing photo keep its
filename. For a new one, write the filename you'll use next to the slot.
Long edge ≥ 1600 px, JPG. I place the en/em-dashes, „Czech quotes" and
non-breaking spaces — just write plain text.

`img:` = photo(s) shown with the post (comma-separate for a set).
`link:` = a button under the post — write it as `Button label → https://…`
